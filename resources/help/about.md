# DBC Compare Tool

**Version {version}** · Developed by **Long Vo Thien** · MIT License

[Original repository: longvo92/dbc-compare-tool](https://github.com/longvo92/dbc-compare-tool)

DBC Compare Tool compares two versions of a CAN database. Use it to see which messages, signals and ECU routes changed between the OLD and NEW baselines before integrating a DBC update.

## What you can do

- **Compare files or folders.** Review added, removed, modified and renamed messages and signals across two DBC files or entire baseline folders.
- **Inspect the details.** See OLD and NEW values for properties such as CAN ID, signal layout and scaling, plus ECU Tx/Rx routing.
- **Focus on selected ECUs.** Pick one or more nodes to include changes related to their Tx/Rx routes on either baseline. You can pair ECU nodes that were renamed.
- **Share an Excel report.** Review change totals, message and signal details, and warnings when a folder comparison skips unreadable files.

Use the Windows GUI for interactive review or the CLI for scripted comparisons. The GUI and Excel report can each use English or Vietnamese.
