[longvo92/dbc-compare-tool](https://github.com/longvo92/dbc-compare-tool)

DBC Compare Tool answers one question before an integration: what changed between two DBC baselines, and who is affected by it.

## What you can do

- **Compare DBC files or folders.** Review added, removed, modified and renamed messages and signals, with OLD and NEW values for CAN ID, signal layout, scaling and ECU Tx/Rx routing.
- **Pair what was renamed.** Automatic pairing for files, messages and signals, manual DBC pairing when you know better, and ECU node pairing so a renamed node is not read as a routing change.
- **Focus on selected ECUs.** Limit the report to changes on chosen nodes, across both baselines.
- **Share an Excel report.** Change totals, message and signal details, coverage, and warnings when a folder comparison skips unreadable files.

The interface and the Excel report can each use English or Vietnamese, in a light or dark theme.
