# DBC Compare Tool

**Phiên bản {version}** · Phát triển bởi **Long Vo Thien** · Giấy phép MIT

[longvo92/dbc-compare-tool](https://github.com/longvo92/dbc-compare-tool)

DBC Compare Tool trả lời một câu hỏi trước khi tích hợp: giữa hai baseline DBC có gì thay đổi, và ECU nào bị ảnh hưởng.

## Bạn có thể làm gì

- **So sánh file hoặc folder DBC.** Xem message và signal được thêm, xóa, sửa hoặc đổi tên, cùng giá trị OLD và NEW của CAN ID, vị trí bit, hệ số scale và route Tx/Rx của ECU.
- **Ghép cặp phần đã đổi tên.** Tự động ghép cặp file, message và signal; ghép cặp DBC thủ công khi cần; ghép cặp node ECU để đổi tên node không bị hiểu thành thay đổi route.
- **Tập trung vào ECU cần kiểm tra.** Giới hạn report theo các node đã chọn, xét trên cả hai baseline.
- **Chia sẻ report Excel.** Tổng số thay đổi, chi tiết message và signal, coverage, cùng cảnh báo khi so sánh folder bỏ qua file không đọc được.

Giao diện và report Excel có thể chọn English hoặc Tiếng Việt riêng, với chủ đề sáng hoặc tối.
